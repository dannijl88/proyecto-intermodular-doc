# 2. Introducción

## 2.1 Objetivo del proyecto

**TaskMaster Pro** es una aplicación web sencilla para **gestionar tareas escolares** de forma eficiente. Su objetivo principal es ayudar a **estudiantes** a organizar sus trabajos, exámenes y proyectos académicos.

### **Objetivos específicos:**
1. Permitir crear, editar y eliminar tareas
2. Clasificar tareas por **materias** y **prioridades**
3. Enviar recordatorios por email
4. Generar reportes de progreso
